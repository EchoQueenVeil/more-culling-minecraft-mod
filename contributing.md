## ❓ What Is More Culling

| **Term** | **Description** |
|-----------|-----------------|
| **Culling** | Skipping hidden geometry |

| **Face culling** | Skip hidden block faces |
| **Entity culling** | Skip off-screen mobs |
| **Leaf culling** | Faster foliage |

## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Crash on launch** | Wrong MC version |
| **Missing textures** | Disable leaf culling |
| **Shader artifacts** | Add to ignore list |
| **No FPS gain** | Enable block faces |

| **Mod conflict** | Update both mods |
